**Every prompt below already includes:**
- The shared style prefix (semi-realistic cel-shaded, warm cinematic
  lighting, portrait 2:3, tasteful/age-appropriate clause).
- A batch-variety instruction so the image generator doesn't reuse the same
  face/hair/palette across different books' narrators.
- A gender lock — vary looks, never vary the gender the story assigns each
  character.
- Character look details pulled directly from each book's own `CHARACTERS`
  array in `storybookDataN.js`, so art stays consistent with anything a
  future chapter-illustration pass would need to match.

Filename convention: `src/assets/storybook{N}/cover.jpg` (or `.png`).
