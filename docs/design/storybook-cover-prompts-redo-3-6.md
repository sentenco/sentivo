# Story Book cover-art REDO prompts, Books 3-6 (Teens A1)

Saved 2026-09-13. Story text stays as-is for all 4 books -- this is
art-only, same pattern as the earlier Adults A2 (7-12) cover replacement
(see [[project_storybook_feature_status]]). Send when asked -- copy each
numbered block verbatim, it's self-contained.

Each scene is grounded in that book's actual chapter content (pulled
directly from `storybookDataN.js`), picked to be a fresh, more dynamic
moment than each book's current live cover rather than just re-describing
it. Filename convention: `src/assets/storybook{N}/cover.jpg` (or `.jpeg`)
-- this REPLACES the existing file at that path when wired in.

IMPORTANT: this is one of many covers in the full Story Book batch — vary hair style/color, skin tone, build, and color palette from other covers so characters don't look like the same reused model across different books; do NOT change any character's gender, keep exactly as the story describes.
