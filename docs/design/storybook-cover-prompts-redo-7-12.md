# Story Book cover-art REDO prompts, Books 7-12 (Adults A2)

Saved 2026-09-11. Replaces the existing live covers for all 6 books —
story text/content is staying as-is, this is art-only. Supersedes the
9-12 section of `storybook-cover-prompts-redo-9-13.md` (that file's
Book 13 entry is unrelated and still valid on its own). Send when
asked — copy each numbered block verbatim, it's self-contained.

Each scene is a fresh moment grounded in that book's actual story
content, deliberately different in composition from the cover
currently live for that book (so this doesn't just regenerate the same
shot) — see [[project_storybook_feature_status]] for full chapter text
if a redo needs a different beat. All 6 narrators (Jordan, Casey,
Avery, Riley, Quinn, Morgan) are gender-neutral by design — the story
text never uses a pronoun for them, only their name — so any
presentation is fine as long as each looks like a clearly different
person across the batch.

Filename convention: `src/assets/storybook{N}/cover.jpg` (or `.jpeg`)
— this REPLACES the existing file at that path when wired in.

**7 — A Full and Good Week** (narrator: Jordan; coworker Dan; manager Ms. Reyes)
Bright, semi-realistic cel-shaded digital illustration, warm cinematic lighting, clean bold linework, portrait orientation composed as a tall portrait scene (subject in the lower two-thirds, environment stacked vertically above), no text or logos, tasteful and appropriate for a language-learning classroom, aspect ratio 2:3 (e.g. 1200x1800px). IMPORTANT: this is one of 6 covers in a batch (Books 7-12), each with its own adult narrator whose gender is not specified in the story (no pronoun is ever used for them, only their name) — any presentation is fine, but vary hair style/color, skin tone, build, and color palette so this narrator looks like a clearly different person from the other 5 covers in this batch, not the same model reused. Scene: it's Friday afternoon and Jordan is smiling at their desk as manager Ms. Reyes leans over warmly to say a few kind words about the week's work, coworker Dan visible nearby also smiling, a bright orange evening sky glowing through the office window behind them.
